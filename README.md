# Soul and Scribble

A responsive portfolio website for Anshika Rana, Counselling Psychologist and Expressive Arts Therapist.

## Demo

This site is configured to deploy to GitHub Pages after each push to `main`.
After the first successful deployment, enable **Settings → Pages → Build and deployment → GitHub Actions** in the repository settings.

## Local preview

Open `index.html` in a browser, or serve this folder with any static web server.

## Contact form

The contact form validates the required fields, then opens a pre-filled message in the visitor's email app. It does not send or store form data on the website.

## Project files

- `index.html` — page structure and content
- `styles.css` — responsive styling
- `script.js` — navigation, FAQ, and contact-form interactions
- `assets/` — portraits, portfolio image, and favicon
